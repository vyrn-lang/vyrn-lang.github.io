Tooling

The CLI, the test and bench runner, projects and dependency pinning, and the editors.

Commands

  • The CLIvyrn is one binary. vyrn run needs no other tool, vyrn build writes a native binary, and tests, benchmarks, formatting and docs are subcommands.
  • Testing and benchTests and benchmarks live in the file they are about. vyrn run and vyrn build strip them.

Workspace

  • Projects and dependenciesA single file needs no project. vyrn.json names an entry point and the imports; vyrn.lock pins what a build may fetch, down to the compiler's own tools.
  • EditorsOne VS Code extension and one language server, both answering from the compiler front end itself.
