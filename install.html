Install Vyrn

One command installs one self-contained binary. To uninstall, delete its directory.

Release notes

Checksum verification

Read the script before you run it: install.sh, install.ps1.

  • Downloads the release's own SHA256SUMS
  • Hashes the archive and comparesA mismatch deletes it and installs nothing.
  • Both refusals run on every pushOn all three platforms, against a fake release.

Advanced

Pin a version, check by hand, uninstall, build from source

It installs one archive into ~/.vyrn/bin, or %USERPROFILE%\.vyrn\bin on Windows, and writes nothing outside it.

Pin a tag instead of taking the newest release:

curl -fsSL https://vyrn-lang.github.io/install.sh | VYRN_VERSION=TAG sh

Check a manual download yourself:

sha256sum -c SHA256SUMS

Uninstall:

rm -rf ~/.vyrn

Build from source, for the newest commit or a machine with no archive. It needs a recent Rust toolchain, and clang on PATH for a native binary.

git clone https://github.com/vyrn-lang/vyrn.git cd vyrn/compiler cargo build --release -p vyrn-cli
