Web

The view tree, single-file components, routes and RPC, styling and icons. The whole stack is libraries and generators; the compiler has no web feature.

The page

  • Views and HTMLA view is a function that returns a tree. The server renders it to markup; the browser gets the same tree, and a differ applies what changed.
  • Components: .vyxA .vyx file is one component: a script block of ordinary Vyrn and a template block of markup. A generator compiles it while the program builds, so it is a library, not a compiler feature.
  • Styling and iconsstd/tw writes the theme's utility stylesheet at build time. std/icons turns a pinned icon collection into an import, so a glyph is checked like a name.

The server

  • Routes, RPC and the dev serverstd/ui turns a routes directory into one function from request to response. std/rpc makes a typed call between the two halves. vyrn dev serves both while you work.
