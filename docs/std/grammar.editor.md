# std/grammar.editor

Editor support for the `.syntax` files `std/grammar` reads.

No program links this module, so it costs a program nothing. A tool finds it beside `std/grammar` by its name.

## vyrnCheckGrammar

`fn`, at line 30.

```vyrn
gen fn vyrnCheckGrammar(root: String, path: String) -> Code
```

What the grammar at `path` refuses: the report `syntax` gives where it does not load or does not lower, at its line and column. `root` is the same path.

`fn`, at line 36.

The head of the rule a reference at 1-based `line` and `col` of the grammar at `path` names, as a `path:line:col` anchor, or "" where the name is no rule.

## vyrnCompleteGrammar

`fn`, at line 58.
