# std/task

Waiting for the host: `sleep`, the host's timer, and the run queue.

A function that reaches a wait waits itself, and each call of it is marked `await` (language.md, Waiting).

## sleep

`fn`, at line 11.

```vyrn
fn sleep(ms: Int64)
```

Waits while the host runs other tasks, until `ms` milliseconds after the deadline of the wake this task runs in, or after the start of the program or of the request: the time the task computes before it counts against it.

## joinOr

`fn`, at line 46.

```vyrn
fn joinOr<T>(t: consume Task<T>) -> Joined<T>
```

Waits for `t` as `join` does, but a cancellation of the caller while it waits here answers `Cancelled(t)`, and the caller runs on: it decides to cancel, keep or hand on `t`, and returns. Any other wait the caller reaches after that ends it there. If `t` is cancelled, the caller is cancelled where it waits.

## both

Waits for both tasks: their results, in argument order. If one is cancelled, `both` cancels the other and is cancelled. If the caller is cancelled while it waits here, `both` cancels both tasks.

## race

`fn`, at line 114.

```vyrn
fn race<A, B>(first: consume Task<A>, second: consume Task<B>) -> Race<A, B>
```

The first task to return, in argument order once both started, and its result: `await race(fork f(a), fork sleep(500))`. The other is cancelled where it waits, or released if it returned. If the first to end was cancelled, `race` is cancelled. If the caller is cancelled while it waits here, `race` cancels both tasks.

## room
