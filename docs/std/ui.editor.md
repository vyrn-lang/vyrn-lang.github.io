# std/ui.editor

Editor support for the `.vyx` pages `std/ui` claims.

No program links this module, so a program that uses `std/ui` pays nothing for it. A tool finds it beside `std/ui` by its name.

## vyrnChromeUi

`fn`, at line 20.

```vyrn
gen fn vyrnChromeUi() -> String
```

The chrome stems of a `pages` directory, `layout` and `error`, one per line: a tool grades every other file there against `Page`.

## vyrnSourceUi

`fn`, at line 45.

```vyrn
gen fn vyrnSourceUi(path: String) -> String
```

The Vyrn a tool reads in the `.vyx` page at `path`: its `<script>` at the file's own positions, then the `page` its `<template>` compiles to.
