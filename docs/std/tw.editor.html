std/tw.editor

2 exports, from std/tw.editor.vyrn.

Editor support for the theme modules std/tw writes.

No program links this module, so a program that uses std/tw pays nothing for it. A tool finds it beside std/tw by its name. The function of a theme module whose string argument is a class list, so a tool completes and hovers the theme's classes there.
