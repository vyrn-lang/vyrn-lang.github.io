std/json

11 exports, from std/json.vyrn.

The JSON value tree and its canonical writer.

import { Json, JsonField, emit, emitPretty, jsonEq } from "std/json"
import { parseJson } from "std/jsonread"

This module imports nothing; the reader, std/jsonread, imports it. So a caller that only serializes, such as toJson, links no parser. JNum holds raw number text and objects keep their stored field order, so emit is byte-stable through a parse and generators can depend on the order.

sortKeys fn

std/json.vyrn, line 139
fn sortKeys(j: Json) -> Json

A copy of the tree with every object's fields in byte order, recursively. Use it for one emission (a diff, content-addressed output); the stored order, which mirrors a Map's insertion order, never moves.

emit fn

std/json.vyrn, line 336
fn emit(j: Json) -> String

Emit j as compact JSON, field order as stored.

The writers, copyJson and jsonEq recurse at about two frames a level, so a tree nested past about 450 levels traps at the engine's call cap. parseJson refuses input past 128 levels, so only a tree a program builds that deep can reach the cap; bounding it is the program's job.

emitPretty fn

std/json.vyrn, line 420
fn emitPretty(j: Json, indent: Int64) -> String

Emit j as indented JSON, indent spaces per level, field order as stored. Empty arrays and objects stay compact ([], {}).

jsonEq fn

std/json.vyrn, line 431
fn jsonEq(a: Json, b: Json) -> Bool

Deep structural equality, as equality of canonical emits: emit is injective over Json, because kinds have distinct delimiters, field order is kept and numbers keep their raw text.

jsonEncoders fn

std/json.vyrn, line 439
gen fn jsonEncoders(t: TypeArg) -> Code

Writes the encoders toJson calls: for each root, the function that renders its value, and for each node, the function that builds its Json tree. Generated source cannot spell this module's reserved names, so it writes them as VyrnRt_ placeholders the compiler folds back.

JsonReader type

std/json.vyrn, line 563
type JsonReader = { src: String, n: Int64, pos: Int64, depth: Int64, err: String }

A cursor over one document, which std/jsonread's functions read. It is declared here so that fromJson's generated decoders can name it. depth counts the arrays and objects open at pos; err is the refusal, "" while there is none.
