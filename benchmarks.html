Method

  • Plain C11, safe standard-library Rust, plain JavaScript under node and bun. No hand-written vector code and no threads.
  • Vyrn wasm-opt is the WebAssembly build after wasm-opt -O3; plain Vyrn wasm is the module as the compiler writes it.
  • All seven print the same bytes. 100 runs per engine at its own defaults; p50 and p99 by nearest rank.
  • Build time and build peak memory are medians of three builds. Output is the shipped file: the executable, the .wasm module, or the source for node and bun.
  • The harness runs by hand, not in CI. The record is bench/results/2026-10-17.json; the line beside a program's name is Vyrn's time across all records.
