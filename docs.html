Commands

CommandWhat it does
vyrn run | check | build | test | benchRun, type-check, compile, and run the tests and benchmarks written in the file. Your first program.
vyrn fmt --checkThe canonical formatter. --check is the CI gate.
vyrn docMarkdown API docs from /// comments. The pages on this site are read off the same declarations.
vyrn why <file>Why the compiler decided what it decided. --cost and --contract narrow it. The chapter on ownership.
vyrn emit-gen <file>The source a generator produced.
vyrn serve | dev | routesAn HTTP host, the development server, and the resolved wire table.
vyrn new | add | update | vendor | depsProjects and modules. Remote imports pin in vyrn.lock and cache by sha256.
